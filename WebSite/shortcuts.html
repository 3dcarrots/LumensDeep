Keyboard & Mouse Shortcuts

Supercharge your photo editing workflow with complete hardware hotkeys.

1. File & Project Operations
Shortcut Action Description
Ctrl + O
 Open Photo Open any RAW sensor or standard image file.
Ctrl + S
 Save Sidecar Save non-destructive JSON adjustment sidecar.
Ctrl + E
 Export Image Render full-res 16-bit TIFF, PNG, or JPEG.
Ctrl + Z
 Undo Revert last adjustment action.
Ctrl + Y
 Redo Reapply undone adjustment action.
2. Viewport & Canvas Navigation
Shortcut / Action Action Description
Mouse Wheel
 Smooth Zoom Zoom in / out centered at cursor position.
Ctrl + 0
 Fit View Fit entire photo within available viewport bounds.
Ctrl + 1
 100% 1:1 Scale Inspect photo at native sensor pixel scale.
Middle Drag / Left Drag
 Pan Canvas Pan canvas position smoothly.
3. Editing & Masking Tools
Shortcut Action Description
C
 Crop & Straighten Toggle interactive Rule-of-Thirds crop HUD.
B
 Brush Mask Tool Toggle GPU layer mask brush painting mode.
Right Click + Drag
 Brush Erase Erase painted mask under the cursor.
\
 Before / After Toggle Compare with original unprocessed RAW capture.
V
 Vertical Split Wipe Toggle draggable vertical Before/After split wipe.
H
 Horizontal Split Wipe Toggle draggable horizontal Before/After split wipe.
W
 WB Eyedropper Pick neutral white balance point from canvas.
4. AI Assistant & 3D Neural Map Shortcuts
Shortcut Action Description
Ctrl + Shift + G
 Gemini AI Auto-Correction Run Gemini multi-pass auto-correction on active photo with dampened convergence.
Ctrl + Shift + A
 Batch AI Auto-Correction Sequentially auto-correct all selected keepers or visible photos in Filmstrip.
Ctrl + Shift + F
 1-Click Full Auto Workflow Launch complete end-to-end AI Culling + 3D Depth Assessment + Batch AI Processing.
Escape
 Stop Active AI / Batch Immediately and cleanly cancel running Gemini AI pass or batch queue.
V
 Fast Viewer Mode Toggle sub-50ms instant browsing mode (pauses 32-bit RAW decoding).
Enter (in AI Prompt)
 Send One-Time AI Prompt Execute directive immediately in Gemini and auto-clear input field.
Shift + Enter (in AI Prompt)
 Newline in AI Prompt Insert a line break in the AI prompt edit box.
Ctrl + Shift + C
 2-Phase AI Batch Culling Launch AI Photo Culling dialog with Center 50% Crop optical verification.
Ctrl + Shift + D
 Compute Depth Map Estimate high-resolution 16-bit 3D metric depth map via Marigold.
Ctrl + Shift + N
 Compute Normal Map Estimate high-frequency 3D surface normal vectors.
Ctrl + Shift + S
 Compute Subject Mask Extract sub-pixel hairline subject alpha matting.
Ctrl + Shift + A
 Compute All AI Maps Queue all neural maps for async background calculation.
D
 View Depth Map Toggle 3D depth map visualizer overlay.
N
 View Normal Map Toggle surface normals visualizer overlay.
S
 View Subject Mask Toggle subject segmentation mask visualizer.
M
 View Layer Mask Toggle active layer mask red overlay.
5. Filmstrip, Rating & Photo Culling
Shortcut Action Description
1 – 5
 Star Rating Assign 1 to 5 Stars to the selected photo in Filmstrip.
0
 Clear Rating Reset photo rating to 0 (unrated).
X
 Mark for Deletion (Reject) Flag or unflag photo as rejected (❌).
← / →
 Previous / Next Photo Navigate to adjacent photo in Filmstrip.
Home / End
 First / Last Photo Jump to the first or last photo in the active directory.
